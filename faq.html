幼小衔接

面向哪个年龄阶段？

主要针对5—6岁、中到大班的小朋友，提供学前班、幼小衔接全日制课程。 查看详细说明 →

幼小衔接每班多少孩子？

平均每班约10名孩子。班主任统筹，另外六名分科教师参与相应教学，语文、数学、英语分别由对应科目教师负责；具体在班与任课安排以当期班级为准。 查看详细说明 →

是否安排大量默写拼音和刷题？

不强迫大量默写拼音、刷题或写很多生字。拼音、识字、数学思维以感知和游戏化启蒙为主，不要求硬性默写；重点培养课堂常规、倾听指令、任务意识、时间观念与自理能力。 查看详细说明 →

全年班的一天怎样安排？

原课表8:10—8:30为入校和早读，9:20—9:50为课间操，11:30—12:00为午餐，12:00—14:30包含午间活动、午休和午点，16:10—16:30整理离馆。原表未注明学期，具体时段以当期班级通知为准。 查看详细说明 →

是否重视情绪与同伴相处？

重视情绪管理，引导孩子学习和同学相处、求助、表达情绪、接受挫折。老师耐心引导表达，不打骂、不对比孩子，不只盯着知识点。 查看详细说明 →

少儿英语

英语使用什么教材、班额多大？

采用POWER UP原版教材，搭配瑞格自然拼读，平均每班8—10名孩子。具体分级与当期班型可向Windy老师了解。 查看详细说明 →

幼儿阶段主要学什么？

3—6岁幼儿阶段以听说、模仿、情景互动和可理解输入为主，通过游戏、绘本、歌谣、动画、角色扮演和实物场景接触英语，不以抄写单词、默写和大量应试习题为主。 查看详细说明 →

孩子暂时不愿意开口怎么办？

允许孩子有沉默期，不逼迫当众表演，鼓励自由表达，保护开口自信。课堂建立容错氛围，先鼓励表达，再温和修正。 查看详细说明 →

家里需要做很多书面作业、买很多教具吗？

家庭任务以听音频和亲子互动为主，书面作业较少。不需要大量购买昂贵课外书和教具；配套音频、绘本资源免费或低成本，具体资源与费用以当期安排为准。 查看详细说明 →

如何了解孩子进度、什么时候升班？

通过课堂回放或课堂反馈，说明听力、认读、开口输出和词汇理解的阶段与需要支持之处；评估采用角色扮演、听指令等场景化、游戏化方式，升班依据能力进展，不单按年龄或已上课时判断。 查看详细说明 →

在校生活

全日班在哪里吃饭和午休？

校区有独立食堂，全职厨师和配菜人员，餐具配专业消毒柜，每周制定食谱。设独立睡房，每个孩子配独立睡床，一人一床。 查看详细说明 →

是否安排课间和户外活动？

日常有课间操、户外活动和眼保健操，每周安排适度体育户外课程。原课表周二、周四8:40—9:20列户外体能；月度户外或社会实践按当月通知安排。 查看详细说明 →

收费、请假和退费规则在哪里了解？

报名前向课程老师核对当期课程、费用项目及书面合同，逐项了解餐费、材料、请假、补课、调班和退费条款。具体金额和计算方式以当期书面约定为准。 查看详细说明 →
